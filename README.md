# Ayush Raj Portfolio

Production-ready personal portfolio for Ayush Raj, built with Vite, React, TypeScript, Tailwind CSS, Framer Motion, shadcn/ui-style primitives, and Lucide React.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Vercel Deployment

1. Import this repository into Vercel.
2. Use `npm run build` as the build command.
3. Use `dist` as the output directory.
4. Add the custom domain `ayushraj.tech` in Project Settings > Domains.

No environment variables are required.

## Notes

- Theme defaults to system preference and persists in `localStorage`.
- Command palette shortcut: `Ctrl+K` or `Cmd+K`.
- Konami code toggles terminal mode.
- Replace placeholder contact/profile values with final production links when available.
